This is a barebones template for a Game Design Document in markdown format. Feel free to use for your own projects, but credit is appreciated
# How to use
## Markdown Template
- To set up, copy `MarkdownTemplate.md` to your desired folder and rename it to something you'll remember. I recommend `GDDTemplate.md`
- When you want to create a new design document, duplicate the template file and rename the copy to the name of your game
- You can add/remove sections from the design document if needed to suit your game
## Obsidian Template
- Copy `ObsidianTemplate` to your desired folder and rename it to something you'll remember. I recommend `GDDTemplate`
- When you want to make a new design folder, duplicate the template folder and rename the copy to the name of your game
- Not only can you add new sections to your design document, you can link notes together to make it easier to navigate. This can be especially useful for the Narrative and Mechanics sections
